# Изменения

## 1.0.1

- Базовый образ сменён с Alpine на `node:22-bookworm-slim`. Движок iii
  публикуется только под glibc (ассеты релиза — `*-unknown-linux-gnu`,
  musl-сборки нет), поэтому на Alpine скачанный бинарь падал с
  `spawn /root/.agentmemory/bin/iii ENOENT` — отсутствует загрузчик glibc.
- `HOME=/data` экспортируется в `run.sh`: через `environment` манифеста
  переменная до процесса не доходила, и CLI складывал `.env` и бинарь движка
  в `/root`, то есть вне тома — всё терялось при пересоздании контейнера.
- `init: false` убран: s6-overlay в новом базовом образе нет.

## 1.0.0

- `init: false` — базовые образы Home Assistant несут s6-overlay v3, который
  работает только как PID 1. С `init: true` (значение по умолчанию) дополнение
  падало на старте: `s6-overlay-suexec: fatal: can only run as pid 1`.
- Версия дополнения отвязана от версии npm-пакета: пакет пиннится аргументом
  `AGENTMEMORY_VERSION` в Dockerfile (сейчас 0.9.27).

## 0.9.27

- Первая версия: движок iii + пакет agentmemory, состояние в `/data`,
  сетевой конфиг (0.0.0.0) вместо локального.
