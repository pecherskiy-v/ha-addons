# Изменения

## 1.0.0

- `init: false` — базовые образы Home Assistant несут s6-overlay v3, который
  работает только как PID 1. С `init: true` (значение по умолчанию) дополнение
  падало на старте: `s6-overlay-suexec: fatal: can only run as pid 1`.
- Версия дополнения отвязана от версии npm-пакета: пакет пиннится аргументом
  `AGENTMEMORY_VERSION` в Dockerfile (сейчас 0.9.27).

## 0.9.27

- Первая версия: движок iii + пакет agentmemory, состояние в `/data`,
  сетевой конфиг (0.0.0.0) вместо локального.
