# Cognee

Общая память агентов для всех машин: захватывает промты, вызовы инструментов
и ответы, сжимает их в граф знаний и отдаёт клиентам по MCP.

## Зачем отдельный аддон

Клиенты (Claude Code на маках) подключаются к одному инстансу, поэтому память
не расходится по копиям на каждой машине. Хранилище — уже стоящий рядом
PostgreSQL с pgvector, так что второго векторного движка не появляется.

## Перед запуском

1. Аддон **PostgreSQL with pgvector** должен быть запущен. Он создаёт
   пользователя `ha_user`, базу `ha_db` и включает расширение `vector`.
2. Пароль `ha_user` возьми в конфигурации того аддона (параметр
   `ha_user_password`) и впиши здесь в `db_password`.
3. Проверь, что endpoint моделей доступен с машины Home Assistant.

## Параметры

| параметр | по умолчанию | смысл |
|---|---|---|
| `db_host` | `4061d8e8-postgres-pgvector` | имя хоста аддона Postgres во внутренней сети |
| `db_port` / `db_name` / `db_user` | `5432` / `ha_db` / `ha_user` | реквизиты базы |
| `db_password` | — | пароль `ha_user`, обязателен |
| `llm_provider` / `llm_endpoint` / `llm_model` | `ollama` / `http://192.168.1.74:11434` / `ollama_chat/qwen2.5:7b` | модель для извлечения фактов |
| `embedding_provider` / `embedding_model` / `embedding_dimensions` | `ollama` / `ollama/nomic-embed-text` / `768` | эмбеддинги |
| `allowed_hosts` | `*` | какие Host-заголовки принимать; `*` = доверенная локальная сеть |
| `log_level` | `ERROR` | подробность логов LiteLLM |

`embedding_dimensions` обязано совпадать с реальной размерностью модели,
иначе таблицы pgvector создадутся под неверный размер вектора.

## Подключение клиента

```
claude mcp add cognee -s user --transport http http://<ip-ха>:8001/mcp
```

Если клиент получает `421 Misdirected Request` — его адрес не проходит проверку
Host: добавь его в `allowed_hosts` или оставь `*`.

## Данные

- Таблицы и вектора — в базе `ha_db` рядом с остальными данными, попадают
  в бэкапы аддона Postgres.
- Граф и файлы — в `/data/cognee_data` и `/data/cognee_system`, переживают
  обновление аддона.
