# Changelog

## 1.0.6

- Добавлена опция `dataset_isolation` (по умолчанию выключена). В
  мультитенантном режиме Cognee создаёт отдельную базу на каждый датасет и
  требует у пользователя БД права `CREATE DATABASE`, которых у `ha_user` нет.
  Выключенная изоляция держит всё в одной базе — там же, где бэкап.

## 1.0.5

- Исправлены настройки Ollama по документации cognee: модели указываются без
  префиксов (`qwen3:8b`, `nomic-embed-text:latest`), а эндпоинт эмбеддера —
  с полным путём `/api/embed`. С прежними значениями проверка эмбеддера
  висела до таймаута, хотя сам Ollama отвечает за секунду.

## 1.0.4

- Адаптеру pgvector передаются собственные реквизиты (`VECTOR_DB_*`): при
  включённом контроле доступа он не наследует реляционные и падал с
  «Missing required pgvector credentials» уже после успешных миграций.

## 1.0.3

- Пароль БД больше не дублируется в опциях: при пустом `db_password` аддон сам
  берёт его у аддона PostgreSQL через API супервизора (`db_password_from_addon`).
  Источник правды один — конфигурация того аддона; секрет не копируется руками
  и не проходит через посредников. Для этого добавлены `hassio_api` и роль
  `manager` — она даёт доступ к конфигурации других аддонов, это осознанный
  размен ради единственной пары ключей.
- `db_password` в схеме стал необязательным.

## 1.0.2

- Модель по умолчанию — `ollama_chat/qwen3:8b`: заявленной ранее `qwen2.5:7b`
  на сервере Ollama нет, извлечение фактов падало бы даже при верном пароле.

## 1.0.1

- Исправлен запуск: у базового образа свой `ENTRYPOINT`, из-за чего супервизор
  выполнял `entrypoint.sh /run.sh` и скрипт настройки не отрабатывал —
  аддон падал сразу после старта. Добавлен `ENTRYPOINT []`.

## 1.0.0

- Первая версия. Cognee MCP как аддон Home Assistant: память агентов
  на графе знаний, общая для всех машин в локальной сети.
- Реляционные данные и вектора — в существующем аддоне PostgreSQL с pgvector
  (`DB_PROVIDER=postgres`, `VECTOR_DB_PROVIDER=pgvector`), отдельный
  векторный движок не нужен.
- Граф знаний — встроенный kuzu, файлы в `/data`, отдельного демона нет.
- MCP по HTTP на порту 8001; при `allowed_hosts: "*"` защита от DNS-rebinding
  отключается, иначе клиенты с других машин получают 421.
- Модели по умолчанию — Ollama в локальной сети, наружу ничего не уходит.
