# Golos

Говорит текст на колонке комнаты и возвращает музыку, если она играла.

```
POST http://192.168.4.220:8790/say  {"text": "...", "room": "max", "force": false}
```

- Синтез: Wyoming (Silero) на ПК, голос `voice`.
- Воспроизведение: Music Assistant `play_announcement` прямо на плеер станции.
  Если играла очередь группы — пауза → фраза → та же очередь с той же позиции и громкостью.
- Тихие часы `quiet_from`–`quiet_to`: ответ 409 `{"quiet": true}`, `force` снимает запрет.
- `GET /rooms` — комнаты из настроек, `GET /health` — жив ли сервис.

`ma_token` — долгоживущий токен Music Assistant (Настройки → Профиль → Токены).
