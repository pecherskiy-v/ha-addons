Официальный репозиторий пользовательских дополнений для Home Assistant.

## Доступные аддоны

| Аддон | Описание | Статус |
| :--- | :--- | :--- |
| **Paperclip AI Orchestrator** | Оркестратор AI-агентов с поддержкой Ollama (Windows/Mac) и ComfyUI/SD | Ready |

---

## Как установить аддоны из этого репозитория

1. В вашем Home Assistant перейдите в **Настройки** -> **Дополнения (Add-ons)** -> **Магазин дополнений**.
2. В правом верхнем углу нажмите три точки -> **Репозитории**.
3. Добавьте URL репозитория:
   ```text
   [https://github.com/pecherskiy-v/ha-addons](https://github.com/pecherskiy-v/ha-addons)
