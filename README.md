# Numbuster home add-ons

Репозиторий дополнений Home Assistant: общая инфраструктура памяти агентов на
всегда включённой машине.

## Зачем

Память и векторный индекс раньше жили на клиентских машинах и на Windows-сервере,
который не всегда включён и бывает занят. Здесь они переезжают под супервизор
Home Assistant: он их запускает, следит через watchdog, включает в бэкапы и
показывает в интерфейсе.

Вектора хранятся в PostgreSQL с расширением pgvector — одно хранилище на всё.
Эмбеддинги считает Ollama на машине с видеокартой.

## Дополнения

| Add-on | Порты | Что делает |
|---|---|---|
| Cognee | 8001 | память агентов: граф знаний поверх PostgreSQL с pgvector |

## Установка

Настройки → Дополнения → Магазин → ⋮ → Репозитории → добавить ссылку на этот
репозиторий. Затем поставить нужные дополнения из списка.

## Клиенты

После установки на каждой машине:

```bash
# agentmemory
# ~/.claude.json → mcpServers.agentmemory.env.AGENTMEMORY_URL
#   было:  http://localhost:3111
#   стало: http://<адрес-HA>:3111

# эмбеддер — локально, одинаковая модель на всех машинах
ollama pull nomic-embed-text
```

**Модель эмбеддера обязана совпадать на всех клиентах.** Вектора, посчитанные
разными моделями, несравнимы: поиск начнёт возвращать мусор, а коллекция
молча испортится. Сейчас это `nomic-embed-text` (137M, 768 измерений) — та же,
что использовалась на Windows-сервере.

## Оговорка про Supervised

Дополнения управляются супервизором, поэтому система остаётся `supported` —
в отличие от запуска тех же контейнеров руками через `docker compose`.
