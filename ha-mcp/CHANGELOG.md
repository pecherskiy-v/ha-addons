# Changelog

## 1.0.0

- Первая версия. Сервер ha-mcp переехал с Windows на машину Home Assistant:
  игровую машину выключают, а база нужна постоянно.
- База в `/data`, попадает в резервные копии Home Assistant.
- Код обновляется из git при каждом старте (ветка задаётся опцией `git_ref`).
- Векторный поиск считается в самой базе; Qdrant и другие внешние хранилища
  не нужны.
