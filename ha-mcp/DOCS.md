# ha-mcp

База того, что лежит под рукой: детали, доноры, инструмент, расходники.
Отвечает агентам по MCP, показывает веб-дашборд и отдаёт сенсоры в Home Assistant.

## Почему на машине Home Assistant

Раньше сервер жил на Windows — игровой машине, которую выключают. Здесь он
всегда доступен, а база попадает в резервные копии Home Assistant.

## Параметры

| параметр | по умолчанию | смысл |
|---|---|---|
| `ollama_base` | `http://192.168.1.74:11434` | где считать эмбеддинги и разбирать фото |
| `embed_model` | `nomic-embed-text` | модель эмбеддингов (768 измерений) |
| `chat_model` | `qwen3-vl:8b` | модель для разбора фотографий деталей |
| `git_ref` | `main` | ветка, из которой обновляется код при старте |

Вектора считаются в самой базе (таблица `part_vectors`), отдельное векторное
хранилище не нужно. Без Ollama поиск деградирует до точного и полнотекстового —
всё остальное продолжает работать.

## Данные

`/data/ha-mcp.db` — вся база, переживает обновления аддона. Настройки клиентов —
в `/data/config`.

## Клиенты

На каждой машине в `~/.config/ha-mcp/config.json` указать адрес:

```json
{"api": "http://<ip-ха>:8765"}
```

Проверка: `python3 cli.py stats` покажет адрес сервера и сводку.
